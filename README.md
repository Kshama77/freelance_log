# FreelanceLog

A simple beginner-friendly Java console application to track freelance clients, projects, and payments.

## Features
- Add and view freelance projects
- Track client name, project title, total fee, and payment status
- Mark a project as paid
- View total earnings, paid amount, and outstanding amount
- Uses basic Java classes, `ArrayList`, loops, conditionals, and user input

## Requirements
- Java 8 or later

## Run
Open a terminal in this project folder and run:

```bash
javac -d out src/*.java
java -cp out FreelanceLog
```

## GitHub
Create a repository named `FreelanceLog`, then upload these project files. This project does not require external libraries.
